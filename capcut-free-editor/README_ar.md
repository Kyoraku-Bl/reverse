# CapCut Free — مونتاج فيديو مجاني 100% (بدون خطة مدفوعة)

تطبيق ويب شبيه بتطبيق **CapCut** للمونتاج، يشتغل بالكامل في متصفحك (client-side)، بدون سيرفر، بدون اشتراك، بدون خطة مدفوعة.

## شنوة يعني "مجاني 100%"؟

- **لا سيرفر**: كل المعالجة تتم في متصفحك باستخدام `ffmpeg.wasm` (تشغّل FFmpeg عبر WebAssembly).
- **لا خطة مدفوعة**: جميع الأدوات مفتوحة المصدر (React, Tailwind, ffmpeg.wasm, lucide-react).
- **لا رفع ملفات**: الفيديوهات تبقى على جهازك، ما يروحش لأي سيرفر خارجي.
- **التصدير**: ملف MP4 يصدر مباشرة على جهازك.

## شنوة خدامو (الميزات)

| الميزة | كيفاش |
|--------|-------|
| استيراد وسائط | فيديو، صوت، صورة من جهازك (تبقى محلياً، ما ترتاحش سيرفر) |
| مخطط زمني (Timeline) | مسارات متعددة: فيديو وصوت، تقدر تضيف مسارات جديدة أو تحذفها |
| إضافة كليب | نقر على وسيلة في الشريط الأيسر تضيفها في موقع مؤشر التشغيل، أو اسحب وأفلت |
| تقطيع / تقصير | سحب أطراف الكليب لتعديل المدة |
| نقل كليب | سحب الكليب لتغيير موقعه على المسار نفسه أو مسار آخر |
| قسم كليب (Split) | اختار كليب ثم انقر "قسم الكليب" يقسمه عند موقع مؤشر التشغيل |
| نص overlay | إضافة نص وتحكم في الحجم واللون والشفافية والموقع |
| فلترات فيديو | بدون، أسود وأبيض، عكس الألوان، سيبيا، إبهام، إضاءة، تباين، تشبع |
| تحكم في السرعة | 0.25× إلى 4× (سلاو موشن أو accelerate) |
| تحكم في الصوت | 0% إلى 200% لكل كليب صوتي/فيديو |
| التكبير (Zoom) | تحكم في مقياس التايم لاين (px/ثانية) لرؤية أدق أو أوسع |
| ترجيع / إعادة | Undo و Redo على كل تعديلاتك |
| معاينة | تشغيل الفيديو وتحديد موقع المؤشر |
| تصدير | إنتاج فيديو MP4 نهائي بجودة 720p/1080p/4K |
| حفظ محلي | المشروع يظل في الذاكرة أثناء الجلسة (تجديد الصفحة يمسحه — أعد الاستيراد) |

## كيفاش تشغّله محلياً

```bash
# ادخل للمجلد
cd capcut-free-editor

# ثبت التبعيات
npm ci

# شغّل في وضع التطوير (يفتح المتصفح على http://localhost:5173)
npm run dev

# أو بنّ Produktion
npm run build
npm run preview
```

متطلبات: Node.js (ينصح بإصدار 18+).

## how to use (د steps سريعة)

1. **استورد وسائل**: انقر "استيراد فيديو / صوت / صورة" واختر ملفات من جهازك.
2. **أضف للمخطط الزمني**: انقر على أي وسيلة في الشريط الأيسر — تضاف في موقع مؤشر التشغيل على المسار النشط.
3. **رتب الكليبز**: اسحب الكليبز لتغير مواقعهم، أو اسحب أطرافهم لتقصرهم/تمدهم.
4. **أضف نص**: انقر "إضافة نص" من شريط الأدوات الأسفل، ثمعدل النص واللون والحجم من نفس الشريط.
5. **صيّر/صدّر**: انقر "تصدير الفيديو"، اختر الدقة ومعدل الإطارات، ثم ابدأ التصدير. يتم تحميل ملف MP4 على جهازك.

## ملاحظة تقنية (ffmpeg.wasm)

التصدير يعتمد على `@ffmpeg/ffmpeg` لي يشغّل FFmpeg في المتصفح. الأفلام الكبيرة أو الدقة العالية (4K) قد تستغرق وقتاً لأن المعالجة محلية وتعتمد على قدرة جهازك. لتجربة أسرع ابدأ بـ 720p.

## الخصوصية

كل شيء يقع في متصفحك فقط. لا يتم إرسال أي فيديو أو صوت إلى أي سيرفر، ولا توجد حسابات ولا اشتراكات.
