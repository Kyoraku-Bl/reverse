## 1. كيفاش CapCut خدامو؟ (فهم النظام)

CapCut تطبيق مونتاج فيديو (تطByteDance) متاح على iOS، Android، Windows، Mac، ويب. من 외르 التطبيق يتكون من several قطع تشتغل مع some:

### أ. واجهة المستخدم (UI / Editor)
- **تايم لاين (Timeline):** شريطemporal لي فيه الفيديوهات، الصور، النصوص، والمؤثرات مرتبة على Tracks (مسارات) متعددة.
- **كليب (Clip):** قطعة فيديو أو صوت ليها نقطة بداية، نهاية، سرعة، وتأثيرات.
- **كي فريمز (Keyframes):** نقاط لي تحدد كيفاش特ية معينة (موقع، حجم، شفافية) تتغير مع مرور الوقت (مثلاً تحريك صورة من اليسار لليمين).
- **معاينة فورية (Preview):** عرض الفيديو في الوقت الحقيقي أثناء التعديل.

### ب. محرك المونتاج (Editing Engine)
- يقرا ملفات الفيديو/الصوت، يقطعها، يدمجها، يضيف فلاتر وانتقالات (Transitions)، ويغير السرعة (slow motion / time-lapse).
- في الخلفية Kapital ordinarily يستعمل **FFmpeg** أو مكتبات مماثلة للتفكيك (decoding) والترميز (encoding) بالفيديو (H.264 / H.265 / ProRes...).
- ملف البروجيكت (Project file) غالبًا يكون JSON أو Protobuf لي يخزن كل التعديلات بدون ما يmodify الفيديو الأصلي (non-destructive editing).

### ج. الميزات المدعومة بالذكاء الاصطناعي (AI Features)
- **كپشنات تلقائية (Auto-captions):** Speech-to-text يحول الصوت لنص مضاف على الفيديو.
- **إزالة الخلفية (Background removal):** Cutout للشخص بدون شاشة خضراء (يستعمل عادة موديلات تقسيم الصور / Segmentation).
- **تتبع الأجسام (Object tracking):** تعليق نص أو ملصق على جسم متحرك في الفيديو.
- **بيوتي وتأثيرات الوجه:** تعرّف على معالم الوجه ويطبق فلتر.
- **توصية القوالب (Templates):** اقتراح مونتاجات جاهزة بناءً على الموسيقى أو عدد الكليبز.

### د. التصدير والمزامنة (Export & Sync)
- render النهائي يدمج كل الطبقات كملف فيديو واحد (MP4/MOV) مع جودة مختارة (1080p، 4K، معدل إطارات).
- حفظ المشروع في حساب المستخدم والسحابة (Cloud sync) بين الموبايل والكمبيوتر.

## 2. كيف نستخدم REA لتحليل CapCut؟ (طريقة العمل)

REA (Reverse Engineer Anything) أداة MCP للهندسة العكسية للملفات الثنائية والتطبيقات والسلوك أثناء التشغيل. هنا كيفاش نستخدمها نتفهم CapCut without نبدأ من الصفر:

### خطوة 1: تثبيت REA
```bash
npx rea-agents setup
```
بعدها نخت provider مناسب للهدف (مثلاً Ghidra، IDA، Rizin، Frida، Hopper) — الأدوات Bring-your-own (تثبيتها отдельно)، والقراءة فقط (read-only)، no mutation على الملف الأصلي.

### خطوة 2: اختيار الهدف
- نسخخة سطح المكتب من CapCut (Windows/macOS) — ملف ثنائي (binary) يقدر نحلله.
- أو نسخة الويب/الموبايل لمراقبة الاتصالات (HTTP/WebSocket)/APIs.

### خطوة 3: تحليل ثابت (Static analysis)
مع REA نقدر نشوف:
- struttura ملف البروجيكت (كيفاش يخزن الكليبز، الكي فريمز، والمؤثرات)
- officeffmpeg أو مكتبات المونتاج لي تستعملها internally
- أسماء الدوال المتصلة بالتأثيرات والفلاتر (ل inspiration فقط، لا نسخ كود)

### خطوة 4: مراقبة التشغيل (Dynamic analysis)
مع Frida/process capture عبر REA:
-陪伴 file system: وين writes الفيديوهات المؤقتة، وين يحفظ البروجيكت
- network capture: وين يرسل الـ API (templates، AI captions cloud، إلخ)
- rendering pipeline: ك Befehl ffmpeg لي يتexecute أثناء التصدير

### خطوة 5: استخراج المطلوب للبديل
- نموذج ملف المشروع (JSON schema)
- قائمة المؤثرات والفلاتر الأساسية
- إعدادات التصدير الشائعة ( resolution، bitrate، codec)

> ⚠️ **ملاحظة قانونية:** الهندسة العكسية للاستلهام والتعلم وفهم المفاهيم مسموحة في कई سياقات، ولكن **ممنوع نسخ الكود المحمي بحقوق النشر أو مخالفة Terms of Service**. الخطة هnadekh تبني تطبيق **جديد ومفتوح المصدر** inspiré من ميزات CapCut، لا نسخة منه.

## 3. الخطة المجانية 100% — الستاك التكنولوجي (بدون خطة مدفوعة)

نصيحة: بنällo تطبيق **محلي 우선 (local-first)** — كل شيء يشغل على جهاز المستخدم، لا سيرفر أساسي، لذلك لا تكاليف استضافة.

| الجزء | الأداة المجانية المفتوحة المصدر | الغرض |
|------|------------------------------|-------|
| واجهة ويب | **React + Tailwind CSS** (+ Vite) | شريط المونتاج، التايم لاين، المعاينة |
| واجهة ديسكتوب (اختياري) | **Tauri** (Rust) أو **Electron** | تحويل الويب لتطبيق ويندوز/ماك/لينوكس |
| محرك المونتاج والتصدير | **FFmpeg** (CLI أو ffmpeg.wasm للويب) | قطع، دمج، فلتر، ترميز الفيديو |
| جدولة المونتاج | **MLT Framework** أو منطق مخصص بـ JavaScript/Rust | إدارة التايم لاين،トラック، الكي فريمز |
| الذكاء الاصطناعي - كپشنات | **Whisper** (OpenAI، نموذج مفتوح، يشغل محلي عبر transformers.js / faster-whisper) | تحويل كلام لنص تلقائي |
| الذكاء الاصطناعي - إزالة خلفية | **MediaPipe** (Google) أو **RVM** (実) في المتصفح/محلي | Cutout للشخص بدون شاشة خضراء |
| الذكاء الاصطناعي - تتبع وجه/جسم | **MediaPipe Face Detection / Pose** | تتبع الأجسام وتعليق العناصر |
| معالجة صور | **OpenCV** (wasm أو.native) | فلتر، resize، ألوان، ثبات الصورة |
| تخزين المشاريع محليًا | **IndexedDB** (في المتصفح) أو SQLite (في Tauri) | حفظ البروجيكتات بدون سرفر |
| استضافة (إذا لزم الأمر) | **GitHub Pages / Vercel Hobby / Netlify** (مجاني) | نشر التطبيق الويب مجاناً |

### لماذا هذا مجاني 100%؟
- لاilliserve خاص: كل المعالجة على جهاز المستخدم (Client-side).
- كل الأدوات مرخصة مفتوحة المصدر (MIT / Apache / GPL حسب الأداة) — للتداول والتعديل مجاناً.
- موديلات الذكاء الاصطناعي (Whisper، MediaPipe، OpenCV) تتشغل محلياً بدون API مدفوع.

## 4. خارطة الطريق بالمراحل (MVP → منتج)

### المرحلة 1: MVP — مونتاج أساسي (أسبوعين–شهر)
1. تطبيق React بسيط مع تايم لاين واحد.
2. رفع فيديو/صورة، قص (trim)، دمج Clipين.
3. إضافة نص وموسيقى على الفيديو.
4. تصدير فيديو نهائي عبر FFmpeg (محلياً أو ffmpeg.wasm).
5. حفظ المشروع في IndexedDB.

### المرحلة 2: الذكاء الاصطناعي المجاني (الشهر الثاني)
1. كپشنات تلقائية باستخدام Whisper محلياً.
2. إزالة خلفية للشخص باستخدام MediaPipe.
3. تأثيرات أساسية (فلاتر ألوان، سرعة، تنقل بين الكليبز).

### المرحلة 3: متقدم + ديسكتوب (الشهر الثالث)
1. تطبيق ديسكتوب مع Tauri/Electron لأداء أفضل على فيديوهات كبيرة.
2. كي فريمز للحركة والتحريك.
3. قوالب مونتاج جاهزة (JSON محلي، لا سيرفر).
4. تصدير بجودة مختلفة (720p / 1080p / 4K).

### المرحلة 4: نشر مجاني
- نرفع الويب على **GitHub Pages** أو **Vercel Hobby** — مجاناً للأبد للمشاريع العامة.
- نرفع الديسكتوب على **GitHub Releases** — تحميل مجاني للجميع.
