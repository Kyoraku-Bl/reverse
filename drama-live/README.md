# دراما لايف ويب · Drama Live Web

مشغل بث مباشر (IPTV) كامل يعمل داخل المتصفح — مبني بنفس قائمة ميزات تطبيق **Drama Live**:
M3U / Xtream Codes / أكواد FG، مشاهدة متعددة، مفضلة، PiP، تشغيل في الخلفية، دردشة، دليل برامج (EPG)،
ويعمل على الهاتف والكمبيوتر والتلفاز.

> **ملاحظة قانونية:** المشغّل لا يتضمن ولا يستضيف أي محتوى. القنوات المدمجة هي بثوث اختبارية عامة مجانية،
> والمستخدم هو من يضيف مصدره (اشتراكه أو قائمته).

---

## التشغيل

```bash
npm install
npm run dev        # http://localhost:5173  (تطوير)
npm run build      # فحص الأنواع + بناء الإنتاج إلى dist/
npm run preview    # http://localhost:4173  (معاينة البناء)
npm test           # فحص المنطق + فحص DOM
```

الواجهة افتراضياً بالعربية مع اتجاه RTL، ويمكن التبديل إلى الإنجليزية من الشريط العلوي،
مع مظهر داكن/فاتح.

## الميزات المنفَّذة

| الميزة في التطبيق | التنفيذ في نسخة الويب |
| --- | --- |
| دعم تنسيقات متعددة | رابط M3U/M3U8 · رفع ملف · لصق نص · تسجيل دخول Xtream Codes · كود FG |
| بث بجودة عالية (SD/HD/FHD/4K) | اختيار الجودة من مستويات HLS أو «تلقائي»، مع سقف جودة افتراضي في الإعدادات |
| تشغيل متعدد القنوات | شبكة حتى 4 قنوات معاً، الصوت للقناة المميزة، تبديل بالنقر |
| نظام إعادة الاتصال التلقائي | محاولات متصاعدة (backoff) قابلة للضبط + انتقال تلقائي للخادم الاحتياطي للقناة |
| تنسيقات فيديو متعددة | HLS وMP4/WebM للفيديو، MP3/AAC/OGG للراديو، بث مباشر وVOD |
| تشغيل في الخلفية | وضع «صوت فقط» + Media Session للتحكم من شاشة القفل |
| القنوات المفضلة | علمة بنجمة، محفوظة في المتصفح (localStorage) |
| وضع صورة داخل صورة | زر PiP + اختصار `P` |
| ميزة الدردشة | غرفة دردشة عبر `BroadcastChannel` بين تبويبات ونوافذ المتصفح (بدون خادم) |
| دعم Chromecast / الشاشات كبيرة | زر Cast حقيقي عبر Cast Application Framework (مع تراجع لطيف عند عدم وجود جهاز) + ملء الشاشة + وضع تلفاز بالتنقّل بالأسهم |
| دعم الخوادم المتعددة | دمج الروابط المكررة لنفس القناة في قائمة خوادم مع تبديل يدوي/تلقائي |
| اختيار المسار الصوتي | قائمة مسارات الصوت من `hls.js` |
| الترجمة | قائمة مسارات الترجمة (Subtitle tracks) |
| دليل البرامج | استيراد XMLTV + «الآن/التالي» وشريط تقدّم + دليل تجريبي |
| تطبيق خفيف | بدون تثبيت، PWA قابل للتثبيت، يعمل دون اتصال بعد أول تحميل |
| أقسام وقنوات | بحث فوري، مجموعات، دول، وأقسام (رياضة، أخبار، أطفال، أفلام، وثائقي، موسيقى…) |
| مجاني وبدون إعلانات | لا إعلانات ولا اشتراك ولا ميزات مقفلة |
| توافق بين الأجهزة | RTL عربي/إنجليزي، PWA، اختصارات لوحة مفاتيح، وضع تلفاز |
| إضافات | مؤقّت نوم، قفل أبوين برمز PIN، تصدير M3U، إحصائيات البث المباشرة |

## الاختبار

- `scripts/smoke.ts` — فحص حقيقي لوحدات المنطق: قراءة M3U، دمج الخوادم، ترويسات EXTVLCOPT،
  التصدير وإعادة الاستيراد، أكواد FG، تواريخ XMLTV، دليل البرامج التجريبي، ومطابقة الأقسام.
- `scripts/dom-smoke.mjs` — يبني ملفات TSX الفعلية عبر Vite ويعرض الصفحات الحقيقية داخل jsdom،
  ثم يجرّب المخزن (تحميل قائمة، مفضلة، تفعيل/تعطيل مصدر، تصدير) ويؤكد الحفظ في localStorage.
- `scripts/client-smoke.mjs` — يركّب `<App />` الحقيقي عبر `react-dom/client` (مع تشغيل الـ effects):
  تحميل القائمة التجريبية في أول تشغيل، إرفاق البث بالمشغّل مع كتم الصوت، اختيار قناة بالنقر،
  إضافة للمفضلة، وتبديل اللغة الذي يقلب `lang/dir` على المستند.

- فحوصات إضافية لوحدة `cast.ts`: كشف نوع المحتوى (HLS/MP4/MP3)، رفض روابط udp وTS الخام،
  والتراجع الآمن بدل رمي خطأ عندما لا يوجد SDK أو جهاز.

المجموع: 37 فحصاً (`npm test`).

## ملاحظات تقنية

- بعض سيرفرات IPTV تمنع القراءة المباشرة من المتصفح (CORS) أو تتطلب ترويسات خاصة؛ في هذه الحالة
  تظهر رسالة الخطأ في المشغّل ويمكن تجربة مصدر آخر أو تفعيل `Native HLS` من الإعدادات.
- زر Chromecast يحتاج متصفح Chromium وجهاز استقبال على نفس الشبكة، ولا يعمل داخل iframe مقیَّد؛
  في هذه الحالات يختفي الزر أو تظهر رسالة «لا يوجد جهاز متاح» بدل تعطّل المشغّل.
- كل البيانات (القوائم، المفضلة، الإعدادات، الدردشة) تبقى في المتصفح ولا تُرسل لأي خادم.
